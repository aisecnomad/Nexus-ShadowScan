# Shipping with Adatum Logistics

Adatum Logistics moves palletised freight across the Rotterdam, Katowice
and Vilnius corridors. Book before the lane cut-off and your freight rolls
on the next scheduled departure.

- Booking portal: book before 15:00 local for next-day departure.
- Dangerous goods need the DG annex at booking time.
- Reefer lanes run Monday, Wednesday and Friday.

See the [shipping FAQ](shipping-faq.html) for cut-offs per terminal.
