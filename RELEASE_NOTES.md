# Release notes

The release notes for people who install, configure or operate ShadowScan
(what changes on upgrade and what to do first, one section per release) are
on the documentation site, from
[`docs/release-notes.md`](https://github.com/aisecnomad/Nexus-ShadowScan/blob/main/docs/release-notes.md).
This file was that document until October 2026 and now points there.

- [Unreleased](https://github.com/aisecnomad/Nexus-ShadowScan/blob/main/docs/release-notes.md#unreleased):
  changes on `main` since 0.1.2. They are not published or tagged; pin a
  reviewed commit SHA, and read *Before you upgrade* first, because finding
  ids, risk scores and exit codes change for several connectors.
- 0.1.2 (2026-10-08), the published alpha, and 0.1.1 (2026-10-08), the
  candidate that reached TestPyPI and its tag but not PyPI.

[`CHANGELOG.md`](https://github.com/aisecnomad/Nexus-ShadowScan/blob/main/CHANGELOG.md)
summarizes each release in a short list, the
[engineering log](https://github.com/aisecnomad/Nexus-ShadowScan/blob/main/docs/engineering-log.md)
records every change in detail, and the
[deployment and migration guide](https://github.com/aisecnomad/Nexus-ShadowScan/blob/main/docs/production.md)
has the full upgrade steps.
