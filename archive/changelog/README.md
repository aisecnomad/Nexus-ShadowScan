# Changelog archive

[`CHANGELOG-through-2026-10-16.md`](CHANGELOG-through-2026-10-16.md) is the repository's
[`CHANGELOG.md`](../../CHANGELOG.md) word for word as it stood on 2026-10-16, before the live file was
condensed to one summary per version. It is the engineering log: one long entry per change, with the
reasoning, the regression tests, the alternatives that were tried and not carried, and the figures
behind each claim. The summaries in `CHANGELOG.md` keep what an operator needs (what changed, what it
does not establish, a flag where action is needed) and leave that detail here.

The file is retained as written and is not updated, so where the two differ the live changelog is right
about the current tree and this file is right about what was said at the time. Its SHA-256 is
`2a5f99929c4a255d9f1347cc989a65c983c2a6c07798befc7001158e7fb8d2c1`, and the repository consistency
tests fail if the file changes. The pre-commit whitespace hooks skip `archive/`, so it stays as it was.

Read it as the maintainer's own log. Where it mentions a review, the review was AI-assisted and is not
independent human review (see [governance](../../docs/governance.md)); where it gives scores or counts,
they come from author-written corpora and are not measured field accuracy. It uses the repository's
former name where that was its name.
